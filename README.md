Head of Software Development (Principal Chapter Lead) at [allpay](https://www.allpay.net), a UK payments fintech moving £9.8bn a year. I'm accountable for 65 engineers across 13 squads, and I still write and review code. I started in QA and came up through test lead and chapter lead.

## Leading engineering

- **AI adoption.** Led a department-wide GitHub Copilot rollout, written up in a [Microsoft customer story](https://microsoft.com/en/customers/story/22158-allpay-github-copilot), then built an AI pull request review agent.
- **Platform.** Core platform modernisation: monolith to event-driven .NET on Azure, 80m transactions a year, no disruption.
- **Product.** Principal technical authority on a greenfield consumer banking app, concept to launch, in Go, Flutter and C#.
- **Release safety.** Change control as code: a pipeline stage that blocks a production release unless its change request is approved and matches the exact build going out.
- **People.** Hired for 40+ roles, with 100% retention.
